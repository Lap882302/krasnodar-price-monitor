# Мониторинг цен по Краснодару

Статический интерфейс лежит в папке `docs/` и подходит для GitHub Pages.

## Как опубликовать на GitHub Pages

1. Создайте новый репозиторий на GitHub, например `krasnodar-price-monitor`.
2. Загрузите туда файлы этого проекта.
3. В настройках репозитория откройте `Settings -> Pages`.
4. В `Build and deployment` выберите:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/docs`
5. Сохраните настройки.

Через несколько минут страница будет доступна по адресу:

`https://<github-username>.github.io/krasnodar-price-monitor/`

## Как обновляются данные

Интерфейс читает файл:

`docs/data/latest.json`

Ежедневная автоматизация должна обновлять этот файл и сохранять отчёты в `outputs/`.
После обновления данных нужно сделать commit и `git push origin main`, чтобы GitHub Pages увидел свежий `docs/data/latest.json`.

## Статус источников

- Рынок Онлайн и ВкусВилл уже заведены как первые источники данных.
- Пятёрочка, Яндекс Лавка и Самокат требуют браузерный коннектор: нужно открыть витрину как обычный пользователь, выставить адрес `Краснодар, улица Красная, 156`, затем читать JSON-запросы каталога.
- Азбука Вкуса сначала требует проверки доступности доставки на контрольный адрес в Краснодаре. Если доставки нет, источник должен отображаться как недоступный, а не как пустая цена.

Страница показывает эти статусы в блоке `Подключение магазинов`.

## Контрольный адрес

Краснодар, улица Красная, 156.
