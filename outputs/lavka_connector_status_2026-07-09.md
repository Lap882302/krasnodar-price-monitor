# Яндекс Лавка: статус подключения

Дата проверки: 2026-07-09.

Контрольный адрес: Краснодар, улица Красная, 156.

## Что проверено

- Живое открытие `https://lavka.yandex.ru/` в браузере Codex показало страницу `Вы не робот?`.
- HTML, скачанный прямым запросом, успешно содержит SSR-данные Лавки.
- В SSR-данных есть CSRF-токен и `authProxyCsrfToken`.
- Без адресной пользовательской сессии Лавка отдаёт дефолтный московский адрес:
  - `cityId`: 213
  - `depotId`: 116365
  - депо: `107076, г. Москва, ул. Краснобогатырская, д.79`

## Что добавлено

Добавлен диагностический скрипт:

```bash
node scripts/lavka_ssr_probe.mjs
```

Он умеет:

- читать SSR-данные из живой страницы Лавки;
- читать SSR-данные из сохранённого HTML через `--html`;
- показывать город, адрес депо, `depotId`, статус сервиса и наличие токенов;
- принимать cookie браузерной сессии через `LAVKA_COOKIE`.

## Следующий шаг

1. Открыть Яндекс Лавку в обычном браузере.
2. Пройти капчу, если она появляется.
3. Выставить адрес `Краснодар, улица Красная, 156`.
4. Взять cookie этой сессии и запустить:

```bash
LAVKA_COOKIE="..." node scripts/lavka_ssr_probe.mjs
```

Если после этого probe покажет Краснодарский адрес/депо, можно подключать второй шаг: чтение JSON-запросов каталога и поиск товаров по списку.

Личные cookies нельзя коммитить в репозиторий.
