# Промпт для ручного запуска мониторинга цен

Скопируйте этот текст в новый запрос Codex, если нужно запустить сбор цен вручную прямо сейчас:

```text
Запусти мониторинг цен по Краснодару для контрольного адреса: Краснодар, улица Красная, 156.

Используй инструкцию из файла work/price_monitor/daily_prompt.md.

Проверь типы товаров:
- Помидор
- Клубника
- Картофель
- Курица
- Огурец
- Черешня
- Лук
- Болгарский перец
- Морковь
- Укроп
- Говядина

Сравни источники:
- Рынок Онлайн
- ВкусВилл
- Пятёрочка
- Азбука Вкуса
- Яндекс Лавка
- Самокат

Все цены приведи к руб/кг.

Сохрани результат в:
- outputs/price_monitor_YYYY-MM-DD.csv
- outputs/price_monitor_YYYY-MM-DD.md

В конце дай короткую сводку: какие источники удалось собрать, где был нужен адрес, где товара не было.
```
